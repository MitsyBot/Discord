## O que isso faz???
Esse é o repositorio de desenvolvimento da mitsy, seja bem vindo.

## Executando a mitsy:

* Para rodar uma instância da Mitsy você precisarar os seguintes softwares de terceiros: git, nodejs, npm.
Consulte a documentação do seu Sistema Operacional para instalar.
* Para o serviço funcionar como deveria você tera que rodar outros serviços como por exemplo a [API](https://github.com/MitsyBot/API)

- Baixe o source code utilizando ```git clone https://github.com/MitsyBot/Mitsy```
- Instale as dependencias com o npm: ```npm i```
- Configure o [.env](https://github.com/MitsyBot/Mitsy/blob/master/.env.template)
- Execute a mitsy utilizando ```npm run start```


- Observação: **Em algumas instancias a mitsy pode ter problemas ao executar slashcommands isso não é um problema do bot (ou talvez seja mas eu não encontrei o que causa isso, para desenvolvimento usar a instancia canary do servidor de desenvolvimento e comunidade)**
