## Como iniciar o bot

> Instale o nodejs 14 ou maior: <https://nodejs.org>

> Crie um arquivo chamado `.env` e insira as informações

```
DISCORD_TOKEN=
BOT_PREFIX=
MONGO_URI=
SHARD_AMOUNT=1
CLUSTER_AMOUNT=1
ENABLE_REGISTRY_RELOAD=true
PRODUCTION=false
BOT_DEVELOPERS=id1,id2
```

> Use esses comandos no terminal

```
npm install
```

```
node .
```
